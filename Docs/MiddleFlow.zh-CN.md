# 中层连续弧度与开合过渡

以用户确认已消除中层穿出的 Middle47 版本为基准，源码与缓存保存在 `Evidence/MiddleFlow/Baseline`。本轮改善约 34%～40% 的刻意抬起感，保护原有搭接方向、非对称造型和外内层。

## 实现

对完整合成中层曲面做 180 次空间与时间联合平滑，空间项考虑相邻顶点，时间项考虑相邻缓存姿态。承载搭接的另一侧边缘保留，瓣腹、侧边至瓣尖的变化沿长度与宽度连续过渡。以已确认安全的朝外方向作为可行域，将原条带运动扩展到周围曲面及前后阶段，新增局部位移上限为 0.06；根部前 10% 固定。

影响从 25% 平滑进入，53.125% 之后严格恢复基准，完全盛开保持一致。仍沿用 33 帧插值、既有工作网格与法线/切线更新，无新增公共接口。

六片花瓣在同一个曲面快照上进行精确三角形检查；密集时间点与缓存节点均参与可行性约束。如提案违反间距或自相交约束，统一缩小变形步长重新检查，无法满足则拒绝缓存。最终提案的接受比例记录在 `Bake/Constraint.txt`。缓存生成与来源校验已更新，重新烘焙需要保留本轮基准缓存。

## 对比与检查

- `Before`：原版 25%～50%、每 0.5 个百分点的固定斜视、侧视及关键俯视图。
- `Final`：编辑器最终候选，同样视角和采样；`Player` 为最终 Windows 画面。
- `Comparison.mp4`：同视角连续展开及反向播放对比，左为基准，右为调整后。
- `Metrics.json`：同网格、同阶段的空间与时间二阶差分统计，是弧度和运动变化的辅助指标。
- `Regression`：全部缓存、中点及额外关键阶段的中层回归。
- `CacheAudit.txt`：外内层、原底部/尖角、根部与阶段边界的缓存一致性。

以上证据均位于 `Evidence/MiddleFlow`。Candidate、CandidateB 是未采用的试验；CandidateC 为最终提案添加缓存节点约束检查之前的几何候选。此前 Middle47 的根部和下部跨层重叠记录继续保留，本轮不宣称整花全部无相交。

最终提案的约束接受比例为 1，未缩小变形步长。34%～40% 重点区域的纵向二阶差分 RMS 下降约 12.1%，时间二阶差分 RMS 下降约 25.7%；这些是同网格、同采样的辅助统计，视觉效果以连续动画为准。整体 30%～44% 区域的时间二阶差分 RMS 下降约 23.8%。

261 个缓存、中点及关键姿态的中层自相交回归通过；小于 47% 的密集记录未检出双侧长度均超过 25% 的中层同层非根部接触。根部、25% 及以前、53.125% 及以后保持基准，外内层和原底部、尖角缓存逐字节一致。

Windows 验证版和正式版构建成功；程序内的密集阶段检查及 Outer58 复查通过。按用户要求，停止尚未结束的 Playback 完整播放压力回归，日志中的该次中断为主动停止，不作为测试通过记录。正式程序已同步至 Builds/Windows/MindState.exe，由用户自行确认外观。临时副本 .validation/MiddleFlow 的递归删除被自动安全策略拦截，因此该副本仍保留；Evidence/MiddleFlow 的基准、对比视频和源码缓存留档保留。
