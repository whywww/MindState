# 58% 展开附近的外层局部穿模修正

以当前 OuterFlow 连续弧度版为基准，只在外层原有平滑之后叠加局部抬高。修改前源码和缓存保存在 `Evidence/Outer58/Baseline`。

## 实现

58% 的残余来自外层 1/0、3/2、5/4 三对搭接。按原搭接次序抬高覆盖在上方的 0、2、4 号瓣局部曲面，避免把下方花瓣推穿覆盖面。对完整合成曲面做三角形接触查询，使用覆盖曲面上方的射线间距作为局部抬高约束，目标余量 0.018；空间上向周围瓣面平滑拓展，避免在补丁边缘产生新的交线。本轮采用竖直抬高，以保留瓣面水平投影轮廓。

沿用 33 帧稀疏补偿与现有工作网格，更新法线、切线、侧壁和包围盒；没有新增公共接口。时间窗在 0.4375～0.53125 平滑进入，0.65625～0.78125 平滑退出，实际无接触的缓存帧不会新增抬高；长度前 30% 固定。原底部和尖角补偿、中层和内层缓存保留。

缓存来源校验已覆盖修改的生成源码；重新生成时从本轮基准缓存叠加修正，不重复累加。该流程与既有历史基准烘焙流程一致，需要保留 `Evidence/Outer58/Baseline/Assets/Flower/Resources/BottomOverlap.bytes` 才能重新生成本轮基准上的修正。
