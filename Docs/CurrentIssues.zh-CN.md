# 当前限制与修复建议

## 已接受的动态接触

用户已接受当前四态表现并要求继续整理。四态共用标准开合路径，附加摆动、下垂与收拢不代表所有角度、时间点都没有几何接触。花瓣编号从 0 开始：外层（Outer）为 L0、中层（Middle）为 L1、内层（Inner）为 L2。

`Tools/Verify.ps1 -Contacts` 输出 `Outputs/Validation/Contacts.csv`，每态采 13 个时间点（0–15 秒），每对花瓣最多记录一个非根部和一个根部交点。最新结果（按唯一花瓣对计）：

| 状态 | 非根部接触 | 说明 |
|---|---:|---|
| 澄明（90% 开合） | 15 对，各时间点固定 | 与原开合姿态一致，均为层间叠压；1.5° 呼吸不改变接触 |
| 凝聚（花苞 10%–13%） | 20 对 | 花苞本身是多层花瓣向内叠压，属于预期形态 |
| 漫游（100% 开合 + 5° 侧倾） | 28 对，随行波交替 | 相邻同层在 7–11 秒行波下中段交替叠压；侧倾是整花旋转，不改变瓣间几何 |
| 幽微（35% 开合 + 下垂 7.5°） | 32 对 | 同层相邻瓣在收拢后交叠，2.5 米近距渲染未见可见伪影 |

若后续需要收紧幽微，可先将开合从 35% 调到 38%，或把下垂从 −7.5° 减到 −6°；漫游可减小行波振幅。当前缓存负责标准开合，不能保证附加旋转、下垂后的间距。整花低头/侧倾只旋转整朵花，不会新增花瓣间穿插；新增接触来自收拢与下垂本身。

## 近看艺术形态的边界

光带的离花间隙按顶点测量，四态最低 1.18 倍当前花冠水平半径；着色器再从 1.02 倍起淡出，两层保障保证丝线不会画到花瓣上。但丝线是薄带而不是体积管，极低机位、极端宽高比下仍可能与轮廓边缘在屏幕上贴得很近；出现争议时优先调大 `baseRadius` 或 `RibbonMinRadius`，不要关掉着色器遮罩。

丝线永远只有一条，靠拖尾按 `_TrailPower`（2.2）渐隐、亮头提亮读作笔尖；可见长度约 0.5～0.7 圈（硬上限 1.5 圈），固定镜头下的截图只是某一瞬间，属于预期。路线形状直接跟随专注/放松（2.5 秒平滑），所以脑电剧烈跳动时线形会有约 2 秒的视觉惯性；不要为了「跟手」把平滑时间降到 0.5 秒以下，否则会跳形。觉得线太慢或太快，调 `FlowerRibbons` 里的绕行周期（16−4A+4R 秒一圈，方向固定不随脑电反向）；觉得太松或太紧，调 `baseRadius` 的系数。回声花固定 50% 大小、中心距 1.70 倍花冠半径（间距跟随回声花自己的平均开合，记忆收成花苞时最小 1.30 倍；相机不随状态移动，回声合拢时自身只放大 8%、朝观众挪 0.12，仍留在主花侧后方）、概括 10～45 秒前（最近 10 秒不参与）；若实际展示中显得太散，可把间距收到 1.50 倍并略提亮度；若觉得记忆太短，可调大 `EchoWindow`（保持 `EchoRecent` 为 10 秒；采样容量 64 秒，超过需同时加大 `EchoCapacity`）。

近看时珍珠底色上的丝状纹路来自既有材质，不在本轮范围内；不要通过压暗或加模糊掩盖。


## 设备与性能

- 回声与光流的视觉顿挫已修复：历史仍每 0.5 秒记录，但显示按线性历史的时间积分连续变化；光流使用实际姿态包围盒插值，裁剪仍使用保守并集。30/60/120 Hz 的闭合、呼吸、冻结恢复和全部 206 个缓存节点检查通过。修复后 1080p、4×MSAA 的 120 秒保守渲染复测 P95 为 5.03 ms、P99 为 5.39 ms；逐帧轨迹和 60 FPS 演示见 `Outputs/MotionContinuityReport.md`。
- BrainLink 的软件模拟、协议和网络测试不能替代实体蓝牙配对、实际 COM 口、佩戴接触与持续输出验收；新电脑完整在线安装仍需在目标机器确认。
- 2026-11-13 在 RTX 3080、1080p、4×MSAA 下，两组各 120 秒的保守完整渲染测试，整体帧耗时 P95 从 55.74 ms 降至 4.79 ms，P99 为 5.27 ms；花朵更新 P95 从 42.76 ms 降至 0.32 ms，花瓣顶点上传为零。测试包含显式 GPU 同步，不等同于窗口呈现 FPS；独立 GPU 查询未返回有效值，原始数据见 `Outputs/PerformanceComparison.md`。
- 完整姿态预计算增加了磁盘和显存占用：当前压缩播放缓存约 1.17 GB，主花与回声花 GPU 姿态缓冲合计约 1.38 GB，另保留基础姿态用于取景和诊断。启动需要加载缓存；每帧不再上传花瓣顶点或在 CPU 重算法线。其他电脑仍需运行性能脚本验收。
- 当前来源签名校验几何源码和配置；若需要抵御缓存文件损坏，可进一步加入成品缓存摘要校验。

## 本地历史产物清理

已移除 Git 管理的旧演示、历史报告和一次性脚本。自动审批拒绝递归删除未受 Git 管理的历史目录，因此 `.validation` 副本、`Evidence`、旧验证构建仍需本机清理；根目录历史日志已逐文件移除。

关闭使用这些目录的程序后，在项目根目录运行：

```powershell
./Tools/CleanGenerated.ps1 -WhatIf  # 查看明确的目标
./Tools/CleanGenerated.ps1          # 清理历史与临时目录
```

该脚本仅处理项目内列出的生成目录与根目录日志，保留 Git 历史、最新 `Builds/Windows` 和 `Builds/BrainLinkTools`。`Outputs` 保留本轮结果，后续运行对应验证会覆盖。
