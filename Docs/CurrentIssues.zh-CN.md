# 当前限制与修复建议

## 已接受的动态接触

用户已接受当前四态表现并要求继续整理。四态共用标准开合路径，附加摆动、下垂与收拢不代表所有角度、时间点都没有几何接触。花瓣编号从 0 开始：外层（Outer）为 L0、中层（Middle）为 L1、内层（Inner）为 L2。

`Tools/Verify.ps1 -Contacts` 输出 `Outputs/Validation/Contacts.csv`，每态采 13 个时间点（0–15 秒），每对花瓣最多记录一个非根部和一个根部交点。最新结果：

| 状态 | 非根部接触 | 说明 |
|---|---:|---|
| 澄明（88% 开合） | 13 处，各时间点固定 | 与原开合姿态一致，均为层间叠压；0.35° 呼吸不改变接触 |
| 凝聚（花苞） | 20–24 处 | 花苞本身是多层花瓣向内叠压，属于预期形态 |
| 漫游（100% 开合） | 13–20 处，随行波交替 | 相邻同层在 6.5–10.5 秒行波下中段交替叠压，例如 L1-P1 × L2-P2、L2-P0 × L2-P1 |
| 幽微（64% 开合 + 下垂） | 15–18 处 | L0-P0 × L0-P1、L0-P2 × L0-P3、L0-P4 × L0-P5 与 L2-P0 × L2-P4、L2-P3 × L2-P4 出现同层中段交叠；2.5 米近距渲染未见可见伪影 |

若后续需要收紧幽微，可先将开合从 64% 调到 66–68%，或把下垂从 −6° 减到 −4°；漫游可减小摆动振幅或去掉 2° 偏斜。当前缓存负责标准开合，不能保证附加旋转、下垂后的间距。


## 设备与性能

- BrainLink 的软件模拟、协议和网络测试不能替代实体蓝牙配对、实际 COM 口、佩戴接触与持续输出验收；新电脑完整在线安装仍需在目标机器确认。
- 稀疏补偿与基础姿态缓存会占用内存并上传顶点；稳定 60 fps 需要在目标机器实测。建议优先测量补偿更新和法线重算，再决定优化范围。
- 当前来源签名校验几何源码和配置；若需要抵御缓存文件损坏，可进一步加入成品缓存摘要校验。

## 本地历史产物清理

已移除 Git 管理的旧演示、历史报告和一次性脚本。自动审批拒绝递归删除未受 Git 管理的历史目录，因此 `.validation` 副本、`Evidence`、旧验证构建仍需本机清理；根目录历史日志已逐文件移除。

关闭使用这些目录的程序后，在项目根目录运行：

```powershell
./Tools/CleanGenerated.ps1 -WhatIf  # 查看明确的目标
./Tools/CleanGenerated.ps1          # 清理历史与临时目录
```

该脚本仅处理项目内列出的生成目录与根目录日志，保留 Git 历史、最新 `Builds/Windows` 和 `Builds/BrainLinkTools`。`Outputs` 保留本轮结果，后续运行对应验证会覆盖。
