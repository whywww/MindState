# 外层七片花瓣的内壁尖角局部修正

2026-11-09。基于已完成底部修正的 PolarEdgeFinal 版本，局部抬出外层全部 7 片花瓣向邻瓣内壁穿出的尖角。整瓣位置、旋转、尺寸和动画节奏未改；HeroPetal.cs 与 ExhibitionPeony.asset 保持本轮修改前内容。

## 修正位置与实现

目标是各片左上侧自由边附近的尖端区域，依次与前一片相邻花瓣接触，P0 与 P6 的首尾接缝一并处理。尖角向下弯曲，不能按世界高度识别：本次使用 UV 尖端区域定位，未放宽原底部拟合的高度限制。

以原有底部补偿后的曲面为输入，对 33 个缓存阶段逐对计算精确网格中面三角形相交。仅保留与尖端或左侧自由边连通的穿入分量，沿接触处邻瓣的局部外法线推到外侧，包含自然产生的少量向上分量，没有沿全局竖轴整体抬动。

目标间距为 0.012 单位，新增局部位移上限为 0.08；实际最大值 0.07348068。交叉范围外围只扩展两圈网格作为过渡，第二圈归零；在尖端修正区域内部平滑衰减，避免下端形成硬折点。新增补偿仅出现在相关闭合阶段，按 33 帧连续插值，完全盛开归零。

新增稀疏补偿与原底部补偿分别保存，合成到原来的 18 个独立工作网格，未新增工作网格。复用受影响区域的法线、切线和侧壁更新；包围盒采用原底部与新增补偿半径之和作为保守扩张。缓存格式升级至 BottomOverlap/2；构建仍核对源码与配置指纹。没有新增公共接口。
